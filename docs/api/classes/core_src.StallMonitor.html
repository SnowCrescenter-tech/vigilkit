    Class StallMonitor

    Episode-aware stall watchdog. noteData records data activity (enqueue or decoder output); onTick runs once per pump tick with whether the pipeline still has data to consume. Declares one stall episode per idle run past stallThresholdMs, accumulates rebuffer time while stalled, and reports fatal once an episode outlives fatalStallMs.
