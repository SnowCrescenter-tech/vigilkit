    Interface VideoCodecDecoder

    Decoder contract consumed by the scheduler/engine. Satisfied by the WebCodecs-backed VideoDecoderWrapper and by soft (WASM/JS) decoders so the pipeline can route between codec implementations without knowing the backend.
