# vigilkit

**Status: v0.1 in development**

vigilkit is an open-source (Apache-2.0) WebCodecs-first, plugin-based web video player SDK for surveillance and IoT video. It streams and renders multi-stream video entirely in the browser.

## Zero telemetry

vigilkit collects no telemetry, analytics, or usage data of any kind. All code runs in the browser, and nothing is ever sent to any vigilkit-operated server.

## Open-core model

The core player and the standard plugin set are Apache-2.0 forever. Enterprise add-ons and vendor protocol customization are the only commercial surface.
