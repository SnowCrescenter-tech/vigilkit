## HEVC TS fixture (generated)

- `hevc-seg-0.ts` (605924 bytes, HEVC stream_type 0x24 MPEG-TS) — generated by
  `node scripts/generate-hevc-fixtures.mjs` from
  `examples/basic/hevc-fixtures/paired_fields.hevc`: PAT (pid 0) + PMT (pid 0x100,
  video pid 0x101) + 10 PES access units (VPS/SPS/PPS + the leading IRAP in the
  first PES, PTS = frameIndex * 90000 / 30). Exercise it with

- `hevc.m3u8` — VOD media playlist, 10 segments of `hevc-seg-0.ts` (TARGETDURATION 1.0s)
