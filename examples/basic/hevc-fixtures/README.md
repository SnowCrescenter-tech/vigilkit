## `flv-hevc.flv` (generated)

Enhanced-RTMP (veovera) FLV wrapping the `paired_fields.hevc` stream, generated by
`node scripts/generate-hevc-fixtures.mjs` and used by the `@vigilkit/plugin-flv`
HEVC demuxer tests and e2e QA.

- FLV header + `onMetaData` (constants 640x360@30, documented — not parsed from the SPS)
- One HEVC SequenceStart tag (codecId nibble = packetType 0, IsExHeader, FourCC `hvc1`,
  box-wrapped hvcC record `[u32 size]['hvcc'][record]`, the ffmpeg/SRS de-facto layout)
- One CodedFrames tag per VCL access unit (frameType nibble + packetType 1, IsExHeader,
  FourCC `hvc1`, SI24 composition time = 0, then 4-byte length-prefixed NALUs);
  key = IRAP NAL type 16..23
- Codec string: `hvc1.4.10.L123.6D.08`; 10 VCL access units; ~592 KB
- `--verify` re-demuxes the file with the plugin demuxer and asserts ≥1 sequence
  header, ≥1 video chunk and 0 errors

Regenerate with `node scripts/generate-hevc-fixtures.mjs --verify` (rebuild the
plugin first so `dist` has the Enhanced-RTMP demuxing path).
